# v0.2.6 发布验证

本版为预发布，保留语音不稳定限制，不宣称完成硬件验收。测试设备为已连接的 FoloToy AI Passport ESP32-C3（芯片修订 v1.1，板卡硬件修订未独立确认）。

## 源码检查

- 独立 Windows Python 3.12 构建环境安装 `tools/requirements-build-exe.txt`，包含固定版本 PyInstaller、Frida 和 esptool；未复制用户的运行配置。
- `python -m unittest discover -s tests -p 'test_*.py'`：97 项通过。
- `ctest --test-dir build-host --output-on-failure`：18 项通过。
- ESP-IDF 5.5.3 在新目录 `build-release-v026` 重新配置并完成全量 ESP32-C3 构建：通过；应用大小 1,740,160 字节，factory 分区可容纳。
- 无新增编译警告。保留原有 recovery 分区命名和容量提示，应用不能写入该 recovery 分区。
- `git diff --check`：通过。

## 包和来源核对

使用干净发布提交运行 `tools/build_easy_release.py`。一体包与独立客户端均出自这一次构建；包内 `notices/BUILD.json` 和 `VERSION.json` 记录实际版本、源码提交及依赖，`SHA256SUMS.txt` 记录校验值。发布前逐个核对 ZIP CRC、清单与文件哈希，并执行升级工具的只读版本查询、串口枚举及客户端启动/退出检查；这些包后检查的最终记录随 Release 附件和说明提供。

首次打包后的启动检查发现，构建机 Python 的 SSL 模块还需要一个附加证书策略资源，冻结包中缺少该文件时会在创建本机 HTTP 客户端前失败。打包配置现按需携带同一资源，保留原有证书校验与附加不信任策略，未禁用验证或降低安全设置。首次失败的包不作为发布附件；修正后重新构建并运行相同启动检查。

升级工具只更新应用区域并在用户确认后备份、校验。发布过程不刷写或重置连接设备，不包括配对文件、作者设置、用户日志、录音、授权凭据或设备完整闪存备份。

## 实机范围

语音联调经过 VB-CABLE / Windows WASAPI / 讯飞。已复现设备回复超时；重启并更换诊断固件后，用户在未移动设备的情况下反馈录音不再中断，但丢帧和播放缓冲不足仍存在。过程及数值见 [联调记录](2026-11-11-win11-voice-continuity.md)。本版本没有证明根因已经解决。

第二台电脑、完整 20 次重连、30 分钟稳定性、macOS、Typeless 和完整豆包实机验收均 NOT RUN。客户端未代码签名。BLE 安全配对、加密要求和协议边界未改动；新增设备诊断只输出计数与时序，不保留载荷或密钥。
