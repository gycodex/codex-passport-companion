# v0.2.5 — 语音缓冲与可靠退出

这是预发布版本。Windows 10/11 x64 用户请下载 **Passport-Windows-x64-v0.2.5.zip**，完整解压后运行 `Passport.exe`。压缩包内同时包含配套固件和独立 USB 升级工具；设备已有 v0.2.4 固件时，电脑端改进不要求重新刷机。

## 本版更新

- 电脑语音桥接在播放前预留约 40 毫秒音频，缓和短暂的蓝牙或网络轮询抖动；录音结束仍会送出不足 40 毫秒的尾音。
- 首次连接失败或断线后，最多再尝试连接三次；仍失败便停止并提示手动重连。刚连上又立即断开的情况也计入失败次数。
- 点击“退出”时，断开设备超时不再阻止桌面窗口关闭；本程序启动的后台若无响应，会在限时等待后终止。浏览器控制台也会在断开失败时继续停止后台。
- 修复 Python 3.10 环境缺少异步 UDP 接口时的局域网设备搜索，保留新版本的原有异步路径。
- 固件版本号更新至 0.2.5，以便一体包中的电脑端和固件能按同一源码提交校验。设备功能与 v0.2.4 相同。

## 使用与验证范围

更新前请从程序或托盘菜单退出旧版 Passport，再解压新包。首次使用及 USB 升级步骤见包内 `先读我-三步开始.md`。语音仍需用户自行安装输入法和虚拟音频驱动，默认关闭。

94 项 Python 测试、18 项主机 C 测试通过；ESP-IDF 5.5.3 干净构建通过。电脑端重连、退出和语音尾音的故障路径由自动化测试覆盖。新版本尚未完成实机长时间录音、20 次重连、30 分钟稳定性及第二台电脑验收；短预缓冲不能修复持续断线。程序未代码签名。
