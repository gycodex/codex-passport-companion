# v0.2.3 — 桌面程序与局域网自动配对

预发布版本。面向 FoloToy AI Passport（ESP32-C3、8 MB Flash）。

## 主要变化

- Windows 单文件 `Passport.exe`：无需另装 Python，提供独立窗口、系统托盘、登录启动选项和首次使用引导。
- 局域网首次连接改为搜索设备、选择设备、核对六位号码并在电脑和设备两端确认；密钥自动保存在本机。
- 手机配网页保存 Wi-Fi 后可直接连接，不再强制下载和转发配对文件；旧版文件导入保留在兼容选项。
- 新配对记住设备标识，IP 变化时可重新发现，仍须使用已保存密钥验证设备。
- 配对使用临时 P256 密钥交换和加密密钥传输；加入会话、渲染代次、超时、取消和尝试频率检查。协议细节见 [LAN-PAIRING.md](../LAN-PAIRING.md)。

## 升级

退出旧版 Passport 后替换桌面程序。局域网自动配对需要同时升级配套固件；仅更新应用分区 0x10000，先备份原应用，保留 NVS、cardid 和 recovery。不要整片擦除或把应用写入 recovery。

已有正确配对仍可使用。旧配置地址失效且没有设备标识时，重新搜索配对；号码不一致则取消。配对限时 30 秒，重新尝试需距上次开始至少 60 秒。

Windows 10/11 x64 需要 WebView2 Runtime。Codex、输入法和虚拟音频驱动仍单独安装。单文件 EXE 内置可选豆包兼容所用 Frida 17.18.0。

## 验证与限制

82 项 Python 测试、18 项 C 主机测试通过；ESP-IDF 5.5.3 全新构建通过。预览固件已在一台设备完成应用备份、刷写校验、重启后局域网发现及配对握手启动。双端确认完成、配对后同步、20 次重连及 30 分钟稳定性测试尚未确认。USB 状态查询有一次超时，网络发现及配对握手正常响应。详见 [验证记录](../validation/2026-09-13-auto-pairing.md)。
