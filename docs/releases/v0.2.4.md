# v0.2.4 — 解压即用的一体包与同步修复

预发布版本。推荐普通 Windows 用户下载 **Passport-Windows-x64-v0.2.4.zip**，不要下载自动生成的 Source code。

## 三步开始

1. **完整解压**，首次安装或升级时用 USB 连接设备，双击“升级设备固件.exe”，核对设备后输入 FLASH。无需 Python，自动备份、校验并保留配网和恢复分区。
2. 打开并登录 Codex，双击 **Passport.exe**。
3. 设备连上 Wi-Fi 后，电脑搜索设备，核对两端六位号码并确认。无需配对文件，之后直接打开程序即可。

包内“先读我-三步开始.md”提供完整说明。Windows 10/11 x64 需要 WebView2 Runtime。

## 本版更新

- 提供主程序、独立 USB 固件升级工具、配套固件、上手说明和校验值的一体包。
- 包含桌面窗口、系统托盘、首次使用引导和局域网自动配对。
- 修复 Windows 会话文件修改时间滞后时，已运行任务在重启桥接后被漏计的问题。
- 修复 Wi-Fi、显示和音频并行时 I2S DMA 缓冲不足导致完成提醒无声的问题。
- 增加只读设备 UI 状态诊断，便于区分任务识别、同步、显示和音频故障。

## 语音是可选功能

任务同步和完成提示音不需要开启语音。语音默认关闭；准备好输入法、虚拟音频驱动后再启用，豆包兼容需要 Windows 授权。升级不会覆盖旧用户的偏好，已有语音配置仍需满足这些条件。

## 验证与已知范围

85 项 Python 测试、18 项 C 主机测试通过，ESP-IDF 5.5.3 干净构建通过。此前同一修复代码已在单台 ESP32-C3 实机完成刷写校验，两端均报告 1 个活动任务，完成测试增加设备完成序号及音频播放计数。

一体包升级工具验证了独立启动、串口枚举与内置 esptool 入口；常规刷写流程使用此前已验证的分区检查和备份逻辑。第二台电脑、完整 20 次重连、30 分钟稳定性和缩小 DMA 缓冲后的持续语音录制仍未完成。程序未代码签名。

所有旧 tag 保留不变，v0.2.4 包含 v0.2.3 之后的任务同步和提示音修复。
