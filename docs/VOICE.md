# 设备麦克风与语音输入

用 Passport 的麦克风说话，由电脑上的输入法识别并输入文字。支持 **蓝牙 / 局域网**，需要本分支新版固件和控制台。

## 先准备

- Windows：安装 [VB-CABLE](https://vb-audio.com/Cable/) 和讯飞或豆包输入法，驱动安装后按官方提示重启。
- macOS：使用 [BlackHole 2ch](https://existential.audio/blackhole/)，并允许运行桥接的 Python 使用蓝牙及辅助功能。Mac 语音尚未实机验证。
- 先按 [控制台说明](CONSOLE.md) 连接设备。设备不会作为系统原生蓝牙麦克风出现，使用语音时必须运行电脑桥接。

## Windows：三步配置

1. **输入法麦克风选 CABLE Output。** 若输入法不能单独选择，在 Windows 声音设置中将它设为默认输入；不要把默认扬声器改成虚拟线。
2. 网页展开「语音输入」，启用设备麦克风，刷新音频设备，输出选 **CABLE Input · Windows WASAPI**。
3. 选择输入法、核对下表快捷键，点击「保存并连接」。旧配置不会自动被新预设覆盖，必要时重新选择输入法。

| 输入法 | 开始 / 结束快捷键 | 额外操作 |
| --- | --- | --- |
| 讯飞 | `f6` | 在讯飞设置中确认语音快捷键是 F6 |
| 豆包 Windows | `alt+v` | 豆包「免按模式」设为左 Alt＋V；网页需要权限时点击「授权并连接」 |
| Typeless / 其他 | 按实际设置填写 | 支持 F1–F12、字母、数字及 Ctrl / Alt / Shift / Win 组合；需自行验证 |

豆包授权后会自动准备可选组件、切换后台并重连，不用手动找管理员脚本。取消授权时原后台保留。使用当前 Windows 用户授权，不能切换其他管理员账户。

## 日常使用

1. 等网页显示「麦克风就绪」，在电脑上点击目标输入框。
2. **设备首页短按下键开始，再按一次结束。** 开始时响一声高短音，结束时响一声低短音；听到开始提示音后再说话。机器人显示说话动画，底部显示分秒计时。
3. 等输入法完成识别；设备不会自动按回车发送文字。

息屏后第一次按键只唤醒屏幕。单次录音最长 2 分钟；离开首页、打开菜单、断连或录音中连续 5 秒收不到轮询会停止。开始录音要求最近 2 秒内桥接在线。

## 蓝牙还是局域网？

两种方式都支持用量、任务、提醒和语音。蓝牙不经过路由器；局域网适合没有蓝牙的电脑。两种方式都需要稳定连接，不能保证蓝牙一定更快。

在设备设置里开启蓝牙会退出 Wi-Fi，开启 Wi-Fi 会退出蓝牙，保留原配对信息。具体方法见 [控制台说明](CONSOLE.md#切换设备连接模式)。蓝牙需要安全配对，协商 MTU 至少 185；数据包过小会提示无法传输语音。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 麦克风就绪，但输入法不开 | 先用电脑键盘测试相同快捷键；豆包检查兼容适配是否就绪 |
| 输入法打开，但没有文字 | 网页输出应为 CABLE Input，输入法输入应为 CABLE Output |
| 文字慢、漏字或录音自行停止 | 看活动日志的停止原因；网络卡顿、丢帧会影响识别，尝试靠近路由器或改用蓝牙对照 |
| 驱动装好但看不到设备 | 退出后台、重新启动，再刷新音频设备 |
| 豆包更新后不能用 | 不要跳过版本校验；关闭自动快捷键，手动启动豆包语音，仅用设备传声音 |

选择「仅测试麦克风」只显示采集状态，不播放音频、不触发输入法。取消「自动触发输入法快捷键」后，可手动打开输入法语音来排查音频链路。

## 豆包兼容范围与隐私

这是非官方、实验性的 Windows 适配：临时连接豆包进程，只处理带 Passport 标记的模拟按键；不修改磁盘上的豆包程序，断开或退出后解除适配。选择豆包会选中兼容设置，可在「快捷键与音频帮助」中关闭。首次使用会请求 Windows 授权并安装可选 Frida 依赖，其他输入法不需要。

当前仅验证 Windows x64 豆包 **0.9.0.0**，且 `ImeService.exe` SHA-256 必须匹配：

```text
94b17bdca571ac3cd2dafa687b4cb8e3a789cda9d044276483003b0a9e8f77a6
```

版本号相同但二进制不同也不会启用适配。其他版本、macOS 豆包、Typeless 尚未验证。

桥接不保存录音或识别文字，只在有界内存队列中传输音频。识别是否上传云端由输入法决定。音频为 16 kHz 单声道 IMA ADPCM，蓝牙使用安全配对链路，局域网使用 AES-256-GCM。电脑端播放前预留约 40 毫秒音频，以缓和轻微轮询抖动；短句结束时会放完不足 40 毫秒的尾音。网络缺帧后不再重复补静音；状态接口提供丢帧、缓冲、停止原因及削波计数。

本机讯飞识别成功、豆包可唤起并识别；蓝牙录音已试用，用户反馈基本可用。延迟、识别率、长时间稳定性和其他电脑仍需验证，详见 [验证记录](RELEASE_CHECKLIST.md)。
