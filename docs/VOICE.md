# 设备麦克风与输入法

第一版通过局域网把 Passport 的麦克风接到电脑已有的语音输入法。
需要本分支的新固件和新版浏览器控制台；旧固件仍能同步用量，但不支持语音。
蓝牙连接继续支持用量和提醒，暂不传输麦克风音频。

## Windows + 讯飞

1. 从 [VB-Audio 官网](https://vb-audio.com/Cable/) 下载 VB-CABLE，解压并以管理员身份运行对应安装程序。官方建议安装后重启电脑。此驱动由第三方提供，遵循其许可。
2. 在讯飞的麦克风设置中选择 **CABLE Output**。如果输入法没有单独选择入口，在系统录音设备中选择它作为默认输入。不要把系统默认扬声器改成虚拟线。
3. 打开 Passport 本机网页，先断开连接，展开“语音输入”。点击“刷新音频设备”，选择 **CABLE Input · Windows WASAPI**，选择讯飞。
4. 开始和结束快捷键预设为 **F6**，请与自己的讯飞设置核对。勾选“启用设备麦克风”，保存并连接。
5. 电脑上先点击目标输入框，在设备首页短按下键开始说话，再次短按下键结束。全程停留首页，待机时底部分两行提示“上键换页  下键语音”和“长按确认菜单”；录音时伙伴显示说话动画和随音量变化的声波，底部显示分秒计时。息屏时第一次按键只唤醒屏幕。

没有安装虚拟线时，可先选择“仅测试麦克风（不传给输入法）”，保存并连接，使用设备按键检查音量。此模式不输出声音、不触发输入法快捷键。

设备不会自动按回车发送消息。快捷键是输入法现有的全局快捷键，开始前请确认当前输入法和焦点；若 F6 结束的行为与当前版本不符，可修改结束快捷键。
可以取消“自动触发输入法快捷键”，手动在电脑上启动和结束输入法语音，仅用设备传声音排查音频。

## Windows + 豆包（实验性）

1. 安装 64 位 Python 3.10+、VB-CABLE 和豆包，选择豆包麦克风为 CABLE Output。
2. 在豆包免按模式设置 **左 Alt＋V**。在控制台选择豆包，开始和结束快捷键均为 `alt+v`，输出选择 CABLE Input · Windows WASAPI。
3. 展开「快捷键与音频帮助」，主动勾选「启用 Windows 豆包兼容适配」，保存设置并退出后台。
4. 使用 `start-console-admin.cmd` 启动，在 Windows UAC 中确认。该入口安装可选的 Frida 依赖；不要在已有普通权限后台仍运行时使用它。
5. 保存并连接，切换至豆包并点击目标输入框，设备首页下键开始／结束说话。

兼容适配在运行中的豆包键盘回调中处理带 Passport 标记的模拟事件。它不修改磁盘上的豆包程序，不处理其他程序的普通模拟按键，断开设备或退出后台会解除适配。这是非官方兼容方式，不是豆包公开承诺支持的 API。

当前仅验证 Windows x64 豆包 0.9.0.0 的下列 **ImeService.exe SHA-256**：

`94b17bdca571ac3cd2dafa687b4cb8e3a789cda9d044276483003b0a9e8f77a6`

版本号相同也可能有不同二进制；哈希不匹配不会安装回调。豆包更新或退出后需要重新验证／连接，切勿只替换哈希或固定地址来跳过检查。可关闭自动快捷键，手动启动输入法，继续把设备用作麦克风。用户已在本机确认适配后可以唤起语音；其他电脑和版本尚未验收。

常规控制台不安装 Frida。手动运行适配时先执行 `python -m pip install -r tools/requirements-doubao.txt`。启用适配后须在同一 Windows 用户下使用管理员启动器，以保留该用户的 Codex 登录和配对配置。

## Typeless 与 Mac

填写输入法实际使用的开始、结束快捷键。组合键使用 `ctrl+alt+space` 格式，支持 `ctrl`、`alt`、`shift`、`cmd`、右 Alt、空格、字母、数字和 F1–F12。

Mac 安装 BlackHole 2ch，桥接输出和输入法麦克风均选 BlackHole，允许运行桥接的 Python 辅助功能权限。Windows 豆包适配不适用于 Mac；Mac 和 Typeless 实机兼容性为 NOT RUN。

## 行为和排查

- 只有设备首页短按下键可以启动录音；网页启用功能只让麦克风待命。
- 录音时显示音量和时长并保持亮屏，结束后恢复原有自动睡眠策略。
- 单次最多 2 分钟。离开首页、打开菜单、断连或 2 秒没有收到电脑轮询都会停止采集。
- 录音期间暂时关闭 Wi-Fi 调制解调器省电，结束后恢复原设置，避免省电唤醒延迟造成丢帧。
- 音频以 16 kHz / 16 位 / 单声道 音频经 IMA ADPCM 压缩后通过原有 AES-256-GCM 连接传输。与用量请求共享连接、串行处理，各有独立任务。
- 固件音频队列上限 320 ms，电脑队列上限 500 ms；拥堵时丢弃旧音频，避免积累长延迟。网页显示麦克风状态，桥接状态接口同时提供丢帧计数。
- 这套代码不保存音频文件或识别文本。识别由输入法完成，是否上传云端取决于输入法自己的设置和政策。
- 没有虚拟线时不会自动改用扬声器。安装驱动后若刷新仍找不到，请退出并重新启动后台，再刷新音频设备。

## 换一台 Windows 电脑

1. 获取 `feature/lan-connection` 分支最新代码，安装 Python 3.10+（建议 64 位 3.12），双击 `start-console.cmd`，启动器会创建环境并安装依赖。
2. 新电脑安装 VB-CABLE 和输入法，设置输入法麦克风为 CABLE Output，并设置语音快捷键。这些设置不会随 Git 同步。
3. 断开旧电脑桥接。新电脑与设备接同一局域网，在网页导入自己的 `passport-lan.json`。文件含配对密钥，请私下复制，不要提交仓库。
4. 展开语音设置，刷新并选择本机 CABLE Input · Windows WASAPI，启用麦克风和快捷键，保存并连接。旧配置不会被预设覆盖：重新选择豆包，或手动填写 `alt+v`。
5. 等待麦克风就绪，点击输入框，设备首页下键开始／结束。本机讯飞 F6 和豆包适配已由用户试用；另一台电脑仍需实测。

配置保存在用户目录 `.codex/passport-console/`，不上传 Git。不要复制 `.venv-console` 到其他电脑。当前设备已有首页语音固件，换电脑无需重刷；其他设备需先刷本分支固件。
