# Passport：三步开始

适用 Windows 10/11 x64 和 FoloToy AI Passport（ESP32-C3、8 MB Flash）。先把整个 ZIP 解压到固定目录，不要在压缩包内直接运行。

## 1. 准备设备（首次安装或升级时做一次）

- 退出旧版 Passport，用 USB 数据线连接设备。
- 双击 **升级设备固件.exe**，核对设备，输入 `FLASH` 并回车。
- 等待显示 **Update verified**，再按回车关闭。原应用会自动备份在 `backups` 文件夹，Wi-Fi、配对信息和恢复分区保留。
- 分区不匹配或校验失败时不要继续；保留升级窗口显示的日志路径。

设备已有本版固件时可以跳过这一步。升级工具需要保留同目录的 `firmware` 文件夹，不需要安装 Python，也不需要输入刷机命令。

## 2. 打开电脑程序

打开并登录自己的 **Codex**，然后双击 **Passport.exe**，按引导点击“下一步：连接设备”。

无需安装 Python。若提示缺少 WebView2，请安装微软 WebView2 Evergreen Runtime 后重开：
https://developer.microsoft.com/microsoft-edge/webview2/

## 3. 连接你的小伙伴

推荐 **局域网 / Wi-Fi**：

1. 在设备“设置 → 无线网络”进入配网。手机连接设备的 Passport Setup 热点，密码看设备屏幕。
2. 手机打开 `http://192.168.4.1`，选择家里的 2.4 GHz Wi-Fi，保存并连接。已经联网可跳过。
3. 电脑点击 **搜索局域网设备**，选择自己的设备，开始配对。
4. 核对电脑与设备的六位号码，一致才在设备按 **OK**，并在电脑点击 **号码一致，确认配对**。

不需要填写 IP，也不需要下载或转发配对文件。电脑可接网线，但必须与设备在同一路由器；访客隔离网络可能无法搜索。

成功后会保存配对并自动连接。首次同步后点击“开始使用”。下次直接双击 Passport.exe；可勾选“打开 Passport 时自动连接设备”。配对限时 30 秒；超时后重试需距上次开始至少 60 秒。

也可选择蓝牙：设备开启蓝牙，电脑搜索连接，并按 Windows 提示输入设备上的六位码。

## 日常使用与常见问题

- 关闭窗口后仍在托盘运行；真正退出请使用程序或托盘菜单中的“退出”。
- 同一设备同时只连接一台电脑；换电脑前退出旧电脑的 Passport。
- 首次连接不会补播历史任务完成提醒。可用“测试提醒”验证当前连接；提示音遵循设备声音设置及夜间静音时间。
- **语音是可选功能，默认关闭。** 基础任务同步和提示音不需要语音驱动或额外授权。语音需自行安装输入法和虚拟音频驱动；豆包兼容还需 Windows 授权。仅准备好这些条件后再启用。
- 旧版配对文件可在“旧固件 / 手动连接”中导入；首次使用本版优先搜索配对。
- 程序未代码签名，请从项目 Release 下载并核对 SHA256SUMS.txt。本包不包含 Codex、输入法或虚拟音频驱动。
