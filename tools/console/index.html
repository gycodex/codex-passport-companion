连接你的 Passport

打开设备设置中的蓝牙开关，让设备靠近电脑，再点击搜索。

跨子网 / 按 IP 查找

填写设备无线网络页面显示的 IP。找到后核对六位码，无需导入配对文件；电脑必须能访问该地址。

让设备与电脑连接同一路由器，无需填写 IP 或导入文件。

核对设备上的六位校验码

仅当两端号码一致时，在设备上按 OK，再点击下方确认。不同则取消。

旧固件 / 手动连接
尚未配对

仅旧固件需要文件。新固件可搜索设备后直接配对。

请先让设备进入蓝牙模式，再在系统配对窗口输入设备显示的配对码。

Codex 默认自动识别，无需填写程序路径。

高级设置
语音输入

用设备麦克风说话，文字输入到当前输入框。支持蓝牙或局域网连接。

选择 CABLE Input，并在输入法中将麦克风设为 CABLE Output。

快捷键与音频帮助

Windows：安装 VB-CABLE，这里选 CABLE Input，输入法的麦克风选 CABLE Output。Mac：使用 BlackHole，两边均选 BlackHole。

适配会临时连接豆包进程，仅支持已验证的 Windows x64 版本。首次使用请阅读 兼容说明。连接时如需权限，网页会引导授权并自动重连，无需手动重启。

豆包使用左 Alt＋V（免按模式），讯飞使用 F6；请与输入法设置保持一致。

点击目标输入框，在设备首页短按下键开始／结束说话，最长 2 分钟。
