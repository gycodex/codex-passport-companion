02 / 设备连接
尚未保存配对密钥

导入设备配网时下载的 passport-lan.json。电脑和设备需在可互通的同一局域网。

请先让设备进入蓝牙模式，再在系统配对窗口输入设备显示的配对码。

高级设置
语音输入 / 讯飞、豆包、Typeless

Passport 作为麦克风，输入法负责识别。第一版需要局域网连接和虚拟音频线。

尚未安装驱动时可选“仅测试麦克风”，查看设备音量；测试模式不触发快捷键。

Windows：安装 VB-CABLE，这里选 CABLE Input，讯飞的麦克风选 CABLE Output。Mac：使用 BlackHole，两边均选 BlackHole。

讯飞预设 F6 开始、F6 结束，可按实际设置修改。切换输入法后请重新填写快捷键。Mac 需允许后台 Python 辅助功能权限。

保存并连接后，在设备菜单打开“语音输入”。先点击电脑上的目标输入框，再按设备确认键开始／结束。不会自动按回车；单次最长 2 分钟。

准备好了，随时可以连接。
