语音输入

用设备麦克风说话，文字输入到当前输入框。需要局域网连接。

选择 CABLE Input，并在输入法中将麦克风设为 CABLE Output。

快捷键与音频帮助

Windows：安装 VB-CABLE，这里选 CABLE Input，输入法的麦克风选 CABLE Output。Mac：使用 BlackHole，两边均选 BlackHole。

适配会临时连接豆包进程，仅支持已验证的 Windows x64 版本。首次使用请阅读 兼容说明；保存后退出后台，使用 start-console-admin.cmd 启动。

豆包使用左 Alt＋V（免按模式），讯飞使用 F6；请与输入法设置保持一致。
